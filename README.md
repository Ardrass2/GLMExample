# GLMExample

В ноутбуке два примера GLM на 1000 эскизах из [CPTSketchGraphs](https://github.com/cvi2snt/CPTSketchGraphs). Используется по одному варианту из каждой выбранной группы. Каждая модель обучается на 800 эскизах и проверяется на 200.

## Bernoulli GLM

Логистическая модель оценивает вероятность наличия ограничения параллельности по количеству отрезков. Доля эскизов с параллельностью составляет 55,3 процента. По модели вероятность растёт с числом отрезков.

На тестовой выборке ROC AUC равен 0,661, точность составляет 63 процента против 55,5 у постоянного прогноза частоты класса. Количество отрезков помогает предсказывать параллельность, но одного признака недостаточно для точного прогноза.

## Poisson GLM

Модель с log link оценивает ожидаемое количество геометрических ограничений по числу геометрических объектов. Прогнозируемое среднее всегда положительно и может быть дробным, хотя сами наблюдения целочисленные.

На тестовой выборке MAE равен 3,49 ограничения, RMSE равен 4,95, Mean Poisson Deviance равна 1,30. Коэффициент дисперсии на обучающей выборке составляет 1,195. Выраженной сверхдисперсии не видно, но это не подтверждает все предположения модели.
